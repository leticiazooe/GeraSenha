🔐 Gerador de Senhas
Um gerador de senhas simples, seguro e personalizável, desenvolvido para ajudar usuários a criarem senhas fortes e únicas para proteger suas contas e dados pessoais.


🚀 Funcionalidades
Geração de senhas aleatórias
Personalização do comprimento da senha
Inclusão de:
Letras maiúsculas
Letras minúsculas
Números
Caracteres especiais

Código limpo e fácil de entender

🛠️ Tecnologias Utilizadas
Linguagem: Python 

📦 Instalação
Clone o repositório:

git clone https://github.com/leticiazooe/gerador-de-senhas.git
cd gerador-de-senhas

Instale as dependências (se houver):

pip install -r requirements.txt

▶️ Como Usar
Execute o script principal:
python gerador_senhas.py
